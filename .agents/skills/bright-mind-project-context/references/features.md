# Feature Map

This is the current product inventory for planning. It is not an implementation commitment.

## User/workspace areas

### Student

Dashboard, learning pathway, courses, assignments, progress, calendar/events, feedback, achievements, XP/streaks, saved resources, notifications, history, and methodology-specific learning tools.

### Teacher

Dashboard, students/classes, invitations, assignments/review, analytics, pathways/recommendations, calendar/live lessons, announcements/resources, content creation, and community courses.

### School

School dashboard, teacher/student/class management, invitations, organization analytics, adoption/completion reporting, events, administrator roles, profile, credentials/accreditation overview, and professional-development tracking.

### Partner / administration

Content dashboard, course builder, activity editors, translation management, media/resources, preview, editorial workflow, moderation/review, pathways, gamification configuration, users/schools where permitted, and audit visibility.

## Learning platform domains

- Bite-sized courses and lessons
- Modular learning/content blocks
- YouTube/media integration
- Reusable interactive activity engine
- Assessments and knowledge checks
- Rule-based personalized learning pathways
- Progress/completion tracking
- Assignments and feedback
- Gamification
- Methodology tools: Active Recall, Design Thinking, Peer-to-Peer Learning, Metacognition
- Community-created educational content
- Credentials/certificates
- Search/discovery
- Notifications/calendar/live learning

## Content lifecycle domains

- Drafting
- Translation
- Review/approval
- Publication/archival
- Revision/version history
- Duplication/templates/reuse
- Moderation/quality control

## Feature specification template

Before implementing a major feature, define:

- Purpose
- Users
- User Experience
- Main Functions
- User Flow
- UI / Visualization
- Data Requirements
- Backend Requirements
- Frontend Requirements
- Permissions
- Localization Requirements
- Gamification Integration
- Analytics
- Dependencies
- Initial delivery vs later expansion

Detailed feature specifications should be added only as features enter planning/implementation, preventing this file from becoming a duplicated mega-specification.
