# Internationalization

## Translate every new Bright Mind feature
Design every new Bright Mind user-facing feature for translation. Distinguish application UI translations from admin-managed educational/content translations.

## Translatable content contracts
Do not store course/activity content in opaque structures that prevent per-locale editing, status tracking, and stale-translation detection. Activity types must identify all translatable learner-visible properties.

## Machine translation remains editable
Machine translation output remains editable and must not become the canonical source automatically.

## Include accessibility and system copy
Media metadata, alternative text, captions, transcripts, feedback, validation, emails, and notifications are translatable where applicable. Consult `I18N.md` before creating schemas or UI that introduce user-facing content.
