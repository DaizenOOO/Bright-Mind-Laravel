# Frontend

## Reuse the existing UI foundation
Reuse existing UI primitives and layout conventions before creating new base components. Use Wayfinder helpers for Laravel routes/actions instead of hard-coded application URLs.

## Workspace UX
Keep student, teacher, school, and partner/admin navigation coherent within one shared design system. Partner/admin workflows must be understandable to non-technical editors; use progressive disclosure, clear status, validation, and preview.

## Accessible learning interactions
Accessibility is required for reusable learning interactions, including keyboard alternatives to drag/drop behavior.

## Reusable component docs
Document reusable Bright Mind components/subsystems under `docs/components/` when their contract becomes meaningful.
