# Roadmap

The repository is currently in architecture/product planning. Phases below establish dependency order; they are not delivery dates.

## Phase 0 — Foundation planning

- Confirm domain boundaries and initial delivery scope
- Identity/RBAC/organizations/schools/classes
- Internationalization/content translation model
- Course/content hierarchy
- Reusable activity architecture
- Editorial/revision/publishing workflow
- Partner admin information architecture
- Privacy/minor/legal decision register
- Production infrastructure baseline

## Phase 1 — Platform foundation

After Phase 0 decisions are approved:

- Bright Mind application shell/branding and locale foundation
- Identity roles/memberships/organization foundations
- Permission enforcement
- Core localized content model
- Editorial statuses/revisions/audit foundations
- Media/resource foundation
- Partner admin shell

## Phase 2 — Core content authoring and delivery

- Course builder and reusable blocks
- Initial activity types
- Translation workflow and DeepL-assisted operations
- Preview/review/publish
- Student course delivery
- Enrollment/progress/completion
- Initial assessment + rule-based recommendations/pathway
- Basic XP/badge integration where pedagogically justified

## Phase 3 — Teaching and school workflows

- Teacher dashboard/classes
- Assignments/submissions/feedback
- Teacher learning analytics
- School administration and organization reporting
- Invitations/onboarding

## Phase 4 — Expansion

- More activity/game types
- Methodology-specific learning tools
- Community course creation/moderation
- Richer pathways/personalization
- Advanced gamification
- Search/discovery improvements
- Live/realtime functionality where justified

## Future / research-dependent

- External European Digital Credentials integration
- AI-assisted recommendations/content workflows where appropriate
- Advanced analytics and integrations

Every phase must preserve multilingual authoring, accessibility, scoped permissions, and non-technical partner usability.
