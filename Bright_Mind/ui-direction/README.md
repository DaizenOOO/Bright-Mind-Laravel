# Bright Mind UI Direction Reference Pack

This folder is visual reference material for Bright Mind. It is not production code.

- Read `DESIGN_REFERENCE_SPEC.md` before designing application UI.
- The screenshots describe visual language and reusable product patterns.
- The approved landing implementation remains authoritative for the public landing page.
- Do not copy unrelated marketplace/commercial behavior from the references.
- Use the references to build Bright Mind-specific student, teacher, school and partner/admin experiences.
- For design-system previews, media and image areas should use plain neutral-gray placeholders with no text inside them.
