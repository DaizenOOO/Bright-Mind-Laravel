# Reference material

Everything under `reference/` is read-only design and implementation evidence for Codex.

- `landing-prototype/` contains the earlier static React prototype source. It is not a production app and must not replace or merge its project configuration into the Laravel root.
- `visual/landing/` contains the approved landing-page visual baseline screenshots.

Codex may inspect and adapt ideas/assets from these files into the canonical Laravel + Inertia + React application. Do not modify files under `reference/` unless the product owner explicitly asks to update the reference itself.
